# Student Management System

Mini Project — Student Management System

## Technology
- Frontend: HTML, CSS, JavaScript
- Backend: Python Flask
- Database: SQLite
- Communication: REST API + JSON + Fetch API

## Features
- Add student
- View all students
- Search by name or roll number
- Update student
- Delete student with confirmation dialog
- Unique roll number validation
- Marks validation (0–100)
- Contact validation (10 digits)
- Dashboard statistics
- Average marks and passing count
- Top performer display
- Grade and pass/fail status
- Progress bars for marks
- Responsive layout
- Light/dark theme toggle
- Dynamic Fetch API updates without page reload

## Run
1. Install Python 3.
2. Open this project folder in VS Code.
3. Create/activate a virtual environment.
4. Run `pip install -r requirements.txt`.
5. Run `python app.py`.
6. Open `http://127.0.0.1:5000`.

The SQLite database `students.db` is created automatically on first run.
